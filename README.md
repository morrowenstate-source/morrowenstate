# Morrowen State

**AI automation & web solutions** · [morrowenstate.com](https://morrowenstate.com)

We build AI assistants, automations and websites for small businesses: booking bots, knowledge-base (RAG) assistants, CRM and API integrations, document processing and reports. We start with the simplest solution that actually solves the problem.

## What we work with

n8n · OpenAI · Pinecone (RAG) · REST APIs · JavaScript · Electron · Telegram API · Google Sheets

- **AI assistants**: chat and booking assistants, RAG over company documents
- **Automation**: n8n workflows, webhooks, CRM / API integrations, reports
- **Web**: landing pages, websites, redesigns

## Demo projects

These are our own demo and learning projects, built to show how a solution works end to end.

| Project | What it does | Stack |
|---|---|---|
| **Altegio AI Booking Assistant** | Chat assistant that checks availability and books appointments through the Altegio API | n8n · OpenAI · Altegio API |
| **RAG Assistants** | Assistants that answer questions from a company's own documents | OpenAI · Pinecone · n8n |
| **Interview Copilot** | Desktop app that helps prepare for and practice interviews, with a Training Mode | Electron · n8n Cloud · OpenAI |
| **Telegram CRM Bot** | Telegram bot that collects leads into a simple CRM table | Telegram API · n8n · Google Sheets |
