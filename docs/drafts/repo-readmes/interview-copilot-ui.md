# Interview Copilot

A desktop app (Electron) that helps prepare for job interviews. The UI sends questions to an **n8n Cloud** workflow that uses **OpenAI** to suggest structured answers. **Training Mode** lets you practise with questions and get feedback.

> Personal project by Oleksandr Melnychenko ([Morrowen State](https://morrowenstate.com)).
