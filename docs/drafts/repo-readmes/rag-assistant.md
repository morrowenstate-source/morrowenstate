# RAG Assistant

A demo assistant that answers questions **from a company's own documents** instead of general knowledge. Documents are split, embedded and stored in **Pinecone**; answers are generated by **OpenAI** using the most relevant passages.

> Demo project by [Morrowen State](https://morrowenstate.com). Not a client deployment.

## How it works
```
Documents → chunks → OpenAI embeddings → Pinecone
Question  → embedding → top matches from Pinecone → OpenAI → answer
```

## Stack

## Run it yourself
1. Create a Pinecone index (dimension matches your embedding model).
2. Import the workflows into n8n and add OpenAI and Pinecone credentials.
3. Run the ingestion workflow on your documents, then ask questions via the chat workflow.
